# Автоколонна 1456 — менеджер паролей

Небольшая программа для хранения рабочих паролей на компьютере Windows.
Интернет и облако не нужны: данные хранятся только на этом компьютере.

## Как установить

1. Скачайте установщик `Avtokolonna1456_Setup.exe`.
2. Запустите его.
3. Нажимайте «Далее».
4. В конце нажмите «Запустить».

Если установщика ещё нет, его должен собрать разработчик на Windows.

После загрузки проекта GitHub сам собирает установщик. Откройте вкладку `Actions`, выберите `Build Windows installer`, откройте последний запуск и скачайте файл `Avtokolonna1456-Installer` в разделе `Artifacts`.

## Первый запуск

1. Придумайте PIN из четырёх цифр.
2. Повторите PIN.
3. Сохраните резервный код в надёжном месте.

Резервный код нужен, если PIN будет забыт. Без него восстановить доступ нельзя.

## Как пользоваться

- Нажмите «Добавить пароль», чтобы создать запись.
- Заполните название, логин, пароль и дату последней смены.
- Дважды нажмите запись, чтобы изменить её.
- Выберите запись и нажмите «Удалить», чтобы удалить её.
- Кнопка с глазом показывает или скрывает пароль.
- Кнопка копирования переносит логин или пароль в буфер обмена.
- Скопированный пароль автоматически удаляется через 30 секунд.

## Цвета и сроки

Пароль нужно менять раз в 90 календарных дней.

- «В порядке» — срок ещё далеко.
- «Скоро» — осталось 7 дней или меньше.
- «Критично» — осталось 3 дня или меньше.
- «Сегодня» — сегодня последний день.
- «Просрочен» — срок уже прошёл.

Программа показывает напоминания внутри приложения и уведомления Windows.
Одинаковое уведомление не повторяется несколько раз в один день.

## Резервная копия

1. Откройте меню с тремя точками.
2. Нажмите «Резервные копии».
3. Нажмите «Создать копию».

Для восстановления выберите копию и нажмите «Восстановить».
Перед восстановлением программа сама сохранит текущие данные.

Резервная копия работает только под той же учётной записью Windows, под которой была создана.

## Где хранятся данные

Данные находятся в папке:

`%APPDATA%\Avtokolonna1456\PasswordManager\`

Файл защищён средствами Windows. Не удаляйте эту папку, если не сделали резервную копию.

## Сборка для разработчика

Сборка выполняется на Windows 10 или Windows 11. Нужны Visual Studio 2022 или Build Tools с компонентом «Разработка классических приложений .NET».

В PowerShell из папки проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Чтобы собрать установщик, дополнительно установите Inno Setup и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\make-installer.ps1
```

Готовый установщик появится в папке `dist`.

На macOS можно редактировать проект и проверять календарную логику, но сам интерфейс WPF, трей, уведомления Windows и установщик проверяются только в Windows.
